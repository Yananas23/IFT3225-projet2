Joueur

GET <path>#/gamers/all

Récupère la liste de tous les joueurs enregistrés dans la base de données.

GET <path>#/gamers/:joueur

Récupère les informations d'un joueur spécifique par son pseudo.

POST <path>#/gamers/add/:pseudo/:pwd

Crée un nouveau joueur avec le pseudo et mot de passe fournis.

Le mot de passe sera chiffré avant d'être stocké.

GET <path>#/gamers/login/:pseudo/:pwd

Permet la connexion d'un joueur avec vérification du mot de passe.

GET <path>#/gamers/logout/:pseudo/:pwd

Déconnecte un joueur et met à jour sa date de dernière connexion.

Mot

GET <path>#/word

Récupère les 10 premiers mots à partir de l'ID 1 avec leurs définitions.

GET <path>#/word/:nb

Récupère un nombre spécifique de mots à partir de l'ID 1 avec leurs définitions.

GET <path>#/word/:nb/:from

Récupère un nombre spécifique de mots à partir d'un ID donné avec leurs définitions.

GET <path>#/word/add?lien=[url]

Importe des mots et définitions à partir d'un fichier en ligne.

Le fichier doit contenir une ligne par mot avec le format: langue source mot définition.

Jeu

GET <path>#/game/play/:pseudo

Incrémente le compteur de parties jouées pour un joueur spécifique.

GET <path>#/game/word/:lg?/:time?/:hint?

GET <path>#/game/def/:lg?/:time?

POST <path>#/game/def/:wordId

Admin

GET <path>#/admin/ping

Vérifie la disponibilité du service.

GET <path>#/admin/top

Récupère les 10 meilleurs joueurs classés par score.

GET <path>#/admin/top/:nb

Récupère les N meilleurs joueurs classés par score.

DELETE <path>#/admin/delete/joueur/:joueur

Supprime un joueur spécifique de la base de données.

DELETE <path>#/admin/delete/def/:id

Supprime une définition spécifique par son ID.

POST <path>#/admin/add/:word/:lang

Ajoute un nouveau mot dans la langue spécifiée.

POST <path>#/admin/add/:word/:lang/:def

Ajoute une définition à un mot existant.
