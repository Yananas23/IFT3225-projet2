Mot

Jeu

Admin

GET /api/users

Récupère la liste de tous les utilisateurs.

POST /api/users

Crée un nouvel utilisateur à partir des données envoyées en JSON.

Exemple de body :

{
  "name": "Jean Dupont",
  "email": "jean@example.com"
}

PUT /api/users/:id

Met à jour les infos d'un utilisateur existant.

DELETE /api/users/:id

Supprime un utilisateur spécifique.
